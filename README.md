Employee Management REST API

This project is a backend REST API built using Python Flask and MySQL.
It provides secure employee management with JWT authentication and basic CRUD operations.

I built this project to understand real-world backend development, authentication, and database integration without using any ORM.

Technologies Used

Python

Flask

MySQL

PyMySQL

Flask-JWT-Extended

Postman (for testing)

Features

JWT-based login authentication

Create, read, update, delete employees

Data stored in MySQL database

Pagination and filtering support

RESTful API design

Tested using Postman
